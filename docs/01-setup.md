# 01 - Inisialisasi Proyek

Langkah awal untuk membangun sistem POS sederhana dengan teknologi modern.

## Perintah yang dijalankan
```bash
npx create-next-app@latest pos-system --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --no-install
```

## Dependensi tambahan
```bash
cd pos-system
npm install prisma --save-dev
npm install @prisma/client
```
